# reBot Flutter Web

## 运行方式

确保本机已安装 Flutter（3.x）并启用 Web：

```bash
flutter config --enable-web
flutter pub get
flutter run -d chrome
```

## 主要文件

- `lib/main.dart`：页面与样式实现
- `pubspec.yaml`：Flutter 项目依赖配置
- `web/index.html`：Web 入口文件
